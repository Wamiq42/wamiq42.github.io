# wamiq42.github.io

Wamiq Uddin — Unity Game Developer portfolio.

Hand-built static site (no frameworks, no templates): HTML, CSS, and vanilla JavaScript.

## Structure

- `index.html` — main page (experience, projects, personal work, skills, contact)
- `projects/` — case study and detail pages for individual games
- `assets/css/style.css` — all styling
- `assets/js/main.js` — nav toggle and scroll-reveal animation
- `images/` — project art and screenshots
